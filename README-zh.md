# 臺北市已立案宗教團體地圖

這是一個以行動裝置為優先的雙語網站，使用公開 ODS 資料集呈現臺北市已立案宗教團體的位置。

[English README](README.md)

## V1.6 — 正式環境準備與輕鬆探索

首頁提供精簡說明，可直接探索目前可見的信仰空間，或繼續瀏覽地圖，不需強制導覽。既有短暫角色動作、動畫偏好與即時文化資訊仍可使用。靜心庭院是可選的中性空間，不要求交談；只開啟庭院或閱讀已審核留言，不會建立訪客或要求投稿驗證。

V1.5程式已合併，但本次實作環境**尚未設定或驗證遠端共享後端**。公開的Presence／Corner旗標及資料庫投稿開關維持關閉。V1.6備妥受控驗證、私人審核／保存期限操作與GitHub Pages／PWA修正，不代表已啟用服務或保證持續可用。啟用前請逐項完成[公開上線檢查表](docs/public-launch-checklist.md)。

共享服務不可用時，可依[展示指南](docs/demo-guide.md)展示完整的單人探索。詳見[系統架構](docs/architecture.md)、[V1.6實測紀錄](docs/release-v1.6.md)、[無障礙檢查](docs/accessibility-review.md)，以及既有的[Supabase設定](docs/supabase-integration.md)、[留言審核](docs/quiet-corner-moderation.md)及[健康檢查](docs/supabase-health-check.md)。本機測試不等於已驗證遠端Auth、雙瀏覽器Presence、公開審核或保存期限排程。

## 專案目的

本專案為「臺北市已立案宗教團體點位資料」提供公開地圖與輕量儀表板。使用者可瀏覽已立案團體的位置、依行政區或宗教別篩選、查看可取得的慶典日期文字，並透過瀏覽器定位功能尋找附近的已立案團體。

## 信仰空間 V1

從地圖標記或團體清單選擇「探索信仰空間」，即可進入道教、佛教、基督教、天主教或伊斯蘭教的原創 SVG 文化場景；其他教別使用中性展間。包含雙語互動熱點、參訪禮儀及可選的 1／3／5 分鐘靜心計時器。所有場景均為文化示意，並非該團體的實際內部配置。

場景按需載入，開啟時保留底層地圖與篩選、附近搜尋、視野狀態。Leaflet popup 使用已跳脫的團體 ID 與限定範圍、可清理的事件代理。雙語內容設定集中於 `src/features/faith-spaces/faithSpaceConfig.ts`；繪圖、對話框、計時器與樣式放在同一功能目錄。靜心活動不會儲存或傳送。

測試沿用 Vitest，新增僅供開發使用的 `@testing-library/react` 與 `jsdom`，分別支援無障礙互動查詢，以及文件、焦點與計時器測試。Windows 若限制系統暫存目錄，可將 `TEMP` 與 `TMP` 指向可寫入的本機目錄後執行 `npm test`。

## 信仰空間 V1.1 — 文化探索

「文化示意」保留自由選擇熱點的方式，並新增可選的「文化導覽」，依原設定順序閱讀相同主題。使用者可自行操作上一個、下一個、完成、重新導覽及退出；切換語言會保留目前進度。導覽進度僅存在 React 記憶體，不會儲存或傳送。「認識這個場所」獨立呈現所選場所的來源支持事實，每段介紹與事實旁附有引用、核對日期，並將政府登記資料另行標示。尚無場所介紹者仍可探索文化示意場景，並看到明確說明。

首批場所包含[松山慈祐宮](https://www.ssjyg.org.tw/About.aspx?View=11)、[艋舺龍山寺](https://whdo.gov.taipei/News_Content.aspx?n=2B790586BA4E1E7A&s=039849E84D5B9C7B&sms=15EB41D4C772E746)、[台北清真寺](https://www.taipeimosque.org.tw/guided.php?lang=tw)與[中山基督長老教會](https://www.sevenstar.org.tw/church/c02004/)。個別建築事實另附對應引用。中性展間新增一貫道、巴哈伊信仰與天理教的有來源簡介，不為這些教別虛構建築或宗教符號。

人工整理的資料存於信仰空間目錄下的 `placeProfiles.ts` 與 `traditionContent.ts`，與產生的政府 JSON 分開維護。場所查找同時比對團體 ID、登記名稱、行政區與地址；資料過期或比對有歧義時不顯示介紹。Vitest 在離線測試中驗證雙語欄位非空、每項敘述的引用、來源中繼資料與 HTTP(S) 網址、核對日期，以及與現有資料集的一對一匹配。來源連結拒絕不安全目的地。文化內容仍由原有功能按需載入。

本版記錄的是內部資料核對，不是宗教社群認可。[雙語文化內容貢獻指南](docs/cultural-content.md)說明編輯流程、來源清單及新增場所方式。已檢視的天主教登記資料多為修會或辦公地址，未能安全對應聖堂，因此暫不建立聖堂介紹；環境音亦因尚未核實合適授權素材而延後。後續編輯工作建議增加外部文化審閱、更多經查證場所及實機／螢幕閱讀器評估，不宣稱尚未完成的社群或無障礙審查。

## V1.2 — 宗教行事曆與文化散步路線

主導覽新增「地圖／行事曆／散步路線」，保留原有地圖篩選、定位及附近搜尋脈絡。行事曆與路線介面首次使用才載入，選擇狀態僅存在 React 記憶體，不新增帳號、分析追蹤或宗教活動紀錄。行事曆項目與路線停靠點可開啟原有信仰空間，或在地圖查看對應的登記場所。

「行事曆」區分資料集原始「祭典參考資料」與有確切日期的已確認活動。政府祭典文字依原文顯示，標示農曆／國曆／未確認曆法；不會換算為今年活動，也不直接填入日曆日期。月曆與清單模式使用 `Asia/Taipei` 顯示人工核對的國曆活動，支援跨日、跨月及跨年日期區間。已確認、取消與延期狀態分別標示，即將舉行清單排除取消或延期活動。首筆具體日期為[主辦單位公告的2026年11月28日至30日艋舺青山宮暗訪暨遶境](https://www.religiouscarnival.com/edcontent.php?id=1155&lang=tw&tb=8)，另有[政府藝文公告](https://www.ilccb.gov.tw/News_Content.aspx?n=10203&s=410445&sms=12921)列出相同日期與免費參與資訊；每日時刻及參與安排仍應向主辦單位確認。活動顯示來源核對日期，並提醒公告可能變動。

「散步路線」首批提供兩組精簡的文化停靠順序：「艋舺三處廟宇文化」（龍山寺 → 青山宮 → 清水巖祖師廟）及「大稻埕的教會與城隍廟」（李春生紀念教會 → 霞海城隍廟）。各站附雙語文化說明與對應機構或政府來源。編號標記表示場所順序，不是經實測的人行路徑；步行導航由外部 Google 地圖提供，若途經點數量或網址長度受限，改提供分段連結。本網站不提供推估時間、距離，也不預設可進入室內、全程無階梯或人行道連續。

人工核對的活動放在 `src/features/religious-calendar/culturalEvents.ts`，原始祭典參考由 `festivalReferences.ts` 分開產生。路線放在 `src/features/cultural-routes/culturalRoutes.ts`。這些內容與 V1.1 場所介紹共用 `src/utils/curatedContent.ts` 的身分、雙語欄位、日期、編輯狀態及來源檢查。活動與路線均須精確匹配登記身分並附公開證據；路線另拒絕座標異常、重複站點與標記失效的登記。無效、有歧義或待核對的內容不顯示。[貢獻指南](docs/cultural-content.md#v12-calendar-and-route-contributions)列有編寫規則及 **2026-11-04** 核對的來源清單。

本版內容由人工維護，收錄規模有限，沒有自動活動資料流、爬蟲、農曆換算或公開參訪保證。來源可用性及活動安排可能變動。後續建議優先重新核對活動與來源、安排有紀錄的外部文化審閱，以及實機／螢幕閱讀器評估。環境音仍延後實作。

## V1.3 — 宗教歷史時間軸與文化故事

主導覽新增按需載入的「歷史與故事」，內含「宗教歷史時間軸」與「臺北信仰文化故事」。時間軸可依教別、行政區及主題篩選，閱讀選定里程碑的內容、來源與相關故事。故事包含導讀、三個自行控制進度的章節及結語，切換章節或語言時保留閱讀狀態。首批提供九則史事與兩個故事：「艋舺廟宇的建築層次」及「建築與群體的不同年代」。

歷史日期保留史料精度，分為確切國曆日期、僅知年份、概略日期、年份區間或日期未確定，不把只有年份的紀錄補成一月一日。已知年代按史料起始年份排序，同年採固定規則，未定日期置於最後。歷史里程碑與行事曆的當代具體活動分開；創建、營建、堂會成立、遷移及古蹟指定也各自說明。

內容存於 `src/features/heritage/historicalMilestones.ts`、`heritageStories.ts` 與現址對照表 `heritageOrganizations.ts`，另有共用型別、驗證與查找工具。章節引用既有里程碑 ID，不另複製時間軸。現址對照必須同時符合政府資料的 ID、完整名稱、行政區及地址；無法安全連結現代場所的章節仍可閱讀。各則史事與章節均附來源，記錄 **2026-11-04** 的內部資料核對，不宣稱宗教社群審閱或場所背書。

「查看目前登記位置」會在原地圖暫時標示現代紀錄；這些座標不能證明歷史位置或範圍。返回歷史與故事時還原閱讀脈絡及先前地圖視野。經查證場所介紹可直接開啟原有信仰空間的「認識這個場所」，相關路線只連結既有人工核對的散步路線。麗水街清真寺舊址章節刻意不連結現址地圖，因為新生南路的登記位置不能驗證舊址座標。

[雙語歷史內容指南](docs/historical-content.md)說明日期精度、身分驗證、章節與史事引用及一手來源。首批依據包括艋舺廟宇的政府文化資產紀錄、[中山教會機構簡史](https://www.sevenstar.org.tw/church/c02004/)與文化資產紀錄，以及[台北清真寺官方歷史](https://www.taipeimosque.org.tw/guided.php?lang=tw)與文化資產紀錄。尚未核實可重用影像及授權，因此暫不加入歷史照片。本功能不重建歷史邊界，也不從現代登記數推定人口或宗教參與趨勢。後續建議優先安排有紀錄的外部文化審閱、重新核對來源及實機視覺／螢幕閱讀器評估。

## V1.4 — 內容品質與無障礙檢查

V1.4 將「認識這個場所」由四筆擴充為八筆內部核對介紹，新增[艋舺青山宮](https://taiwangods.moi.gov.tw/Religious_Culture/html/Cultural/3_0011.aspx?i=211)、[艋舺清水巖祖師廟](https://taiwangods.moi.gov.tw/html/Cultural/3_0011.aspx?i=12)、[台北霞海城隍廟](https://taiwangods.moi.gov.tw/Religious_Culture/html/Cultural/3_0011.aspx?i=58)與[李春生紀念教會](https://www.pct.org.tw/churchdata.aspx?strOrgNo=C03001)。新增內容於 **2026-11-05** 核對，較早來源保留原核對日期。通化街 **178** 號的天主教堂區未附到資料集中 **172** 號的修會紀錄；身分與地址證據優先於增加教別涵蓋數。

場所介紹中的精簡延伸入口，連結安全匹配的歷史里程碑、故事、既有散步路線及具體文化活動，沿用目前導覽並提供返回原場所脈絡的方式，不新增主導覽目的地或儲存閱讀紀錄。

執行 `npm run content:audit` 可離線唯讀檢查場所介紹、教別簡介、活動、路線、歷史里程碑／故事及政府資料品質；加上 `-- --as-of 2026-11-05 --format json` 可取得固定日期的 JSON 報告。結構錯誤使指令失敗，編輯提醒則指出待查核工作，不改寫資料或直接判定主張錯誤。即將舉行活動超過30日未核對、一般參考超過365日未核對會收到注意標記。目前政府快照共 **551筆**、**0項結構錯誤**，有 **341次提醒**：280筆缺少祭典文字、50筆其他／未分類教別、11筆含明確登記狀態註記。類別可能重疊，341不是不同團體的數量；此檢查未改動資料或儀表板總數。

本版加入僅供開發使用的 `axe-core` 檢查，並改善來源清單的標題與地標結構、對話框與載入介面的焦點範圍，以及語言選擇語意。DOM 檢查不能量測實際色彩對比、實機版面或螢幕閱讀器可用性。本環境瀏覽器初始化失敗，因此 V1.4 的320、375、390、768像素及桌面手動檢查、實機、對比與螢幕閱讀器驗證仍未完成。詳見[無障礙檢查紀錄](docs/accessibility-review.md)、[內容稽核指南](docs/content-audit.md)及[已備妥的文化審閱流程](docs/cultural-review-workflow.md)。尚未進行外部社群審閱；文件流程不代表已聯絡、取得同意或獲得背書。

## V1.5a — 信仰片刻

信仰空間加入原創的小型向量訪客。選取熱點後文化資訊立即顯示，角色可選擇短暫走近並觀察；也可走一走、坐下、揮手、觀察或停留。動作不模擬宗教儀式，新動作或關閉場景會取消先前動畫，沒有開場動畫或聲音。

場景提供開啟／關閉動畫，並優先遵守裝置的減少動態效果設定；使用者明確關閉後不會被自動重新開啟。只在本機保存動畫偏好。`VITE_FAITH_MOMENTS_ENABLED=false` 可隱藏角色與控制項；共享服務旗標預設關閉，於獨立版本審閱。詳見[信仰片刻指南](docs/faith-moments.md)及 `.env.example`。

## 座標轉換

ODS 檔案的座標為 TWD97 / TM2，推測使用 EPSG:3826。轉換程式使用 `proj4` 定義 EPSG:3826，將每組「X座標」與「Y座標」轉為 WGS84 經緯度，並在 Leaflet 繪製前，以臺北市的大致範圍驗證結果。

Leaflet 使用的座標順序為 `[緯度, 經度]`。

## 部署

前端沿用GitHub Pages。既有workflow以 `GITHUB_PAGES=true` 建置，將Vite base設為 `/taipei-faith-map/`，並明確關閉兩個共享服務旗標；只發布產生的 `dist` artifact。在本機驗證儲存庫子路徑建置：

```powershell
$env:GITHUB_PAGES = 'true'
npm run build
```

Manifest、圖示、應用程式scope及靜態／延遲載入資源必須在該base下解析。請依[上線檢查表](docs/public-launch-checklist.md)驗證更新、重新整理及離線行為，不假設所有延遲頁面或地圖圖磚可離線使用。Supabase健康檢查是獨立workflow，不部署網站，也不執行特權資料清理。

## 資料聲明

本資料集為已立案宗教團體的資料快照。已立案團體數量不代表其受歡迎程度、信徒人數、出席人數、活動程度或宗教影響力。

實際資訊請以主管機關及現場公告為準。
